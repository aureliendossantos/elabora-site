Elabora est un outil de création de modules e-learning. Cette page concerne :

- le site `elabora.studio` ;
- l'API `api.elabora.studio` ;
- la page de relecture `revue.elabora.studio` ;
- les modules publiés par les auteurs sur `<espace>.elabora.page`.
