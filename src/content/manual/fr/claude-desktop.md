## Ce que donne l’extension

- **Vos modules, dans la conversation de Claude.** Pas de terminal ni de dossier à choisir : Claude voit les modules de votre bibliothèque et ceux ouverts d’ailleurs dans Elabora. Il lit et écrit leur plan, leurs écrans et leurs blocs, les vérifie, regarde un écran comme l’apprenant le voit et construit le paquet SCORM, avec une centaine d’outils qu’Elabora fournit.
- **Les consignes de votre version d’Elabora.** L’extension ne contient pas de copie d’Elabora : elle lance l’app Elabora installée sur votre ordinateur, avec ses règles et ses guides pour chaque tâche. Quand Elabora se met à jour, Claude suit.
- **La main sur tout.** Elabora montre à mesure ce que Claude change, et l’annule en une fois. Voyez [Travailler avec votre IA](/fr/docs/travailler-avec-votre-ia/).

Avec Claude Code, rien à installer : voyez [Elabora et Claude Code](/fr/docs/claude-code/).

## Avant de commencer

- [Elabora](/fr/docs/installer/), installé et ouvert une fois. Sur Mac, dans le dossier Applications.
- L’app [Claude](https://claude.com/download), sur Mac ou sur Windows.

## Installer l’extension

1. Dans Elabora : **Vous** › **Réglages…** › **Outils pour les IA** › **Installer dans Claude**. Le bouton s’affiche quand l’app Claude est sur votre ordinateur. (Ou [téléchargez l’extension](/downloads/elabora.mcpb), `elabora.mcpb`, et double-cliquez dessus.)
2. Claude s’ouvre et montre Elabora : installez-la. Claude peut prévenir que l’extension ne vient pas de son répertoire : l’extension d’Elabora s’installe depuis son fichier.
3. Dans une nouvelle conversation, le menu des outils liste Elabora.

Un module créé ou ouvert ensuite dans Elabora apparaît aussi, sans rien réinstaller.

## Trois demandes à essayer

> Sur quels modules d’Elabora peux-tu travailler ? Donne-moi une vue d’ensemble de chacun.

> Dans le module sur le café, sur la page de l’infusion, ajoute une petite question sur le ratio d’infusion, avec un retour pour chaque réponse.

> Vérifie le module sur le café et dis-moi ce qu’il faut corriger avant de l’envoyer au client.

Avec plusieurs modules, nommez celui dont vous parlez dans votre demande.

## Essayer sur un module d’exemple

[Téléchargez le module d’exemple](/downloads/coffee-in-brief.elabora) « From cherry to cup: coffee in brief », en anglais : un module de 15 minutes pour les nouveaux baristas d’une chaîne de cafés fictive, qui se sert de tous les blocs de départ d’Elabora. Double-cliquez sur le fichier : Elabora l’ajoute à votre bibliothèque, et Claude le voit.

## En cas de problème

- **Claude dit qu’Elabora est introuvable** : sur Mac, Elabora doit être dans le dossier Applications (le vôtre ou celui de l’ordinateur) ; sur Windows, installé avec son installateur. Ouvrez Elabora une fois, puis relancez Claude.
- **Claude dit qu’Elabora n’a pas encore été ouvert** : ouvrez Elabora une fois. Claude voit alors vos modules, sans être relancé.
- **Claude ne propose que la documentation d’Elabora** : mettez Elabora à jour. L’extension demande une version plus récente que la 0.4.0.
