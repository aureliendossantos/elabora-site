Vos relecteurs (votre client, un expert) lisent le module dans leur navigateur, sans compte, et commentent ce qu’ils voient. Leurs commentaires reviennent dans Elabora, à leur place : sur l’écran, le bloc, l’étape, voire le mot de la narration.

## Se connecter à Elabora

La relecture en ligne passe par l’hébergement d’Elabora, qui demande un compte. Pour l’instant, Elabora s’ouvre sur invitation : seules les adresses invitées reçoivent un code.

1. Sur l’accueil, menu **Vous** › **Se connecter à Elabora…**.
2. Entrez votre adresse e-mail, puis **Recevoir un code** ; tapez le code à 8 chiffres reçu par e-mail (valable 10 minutes).
3. La première fois, choisissez l’adresse de votre espace (vous pourrez la changer, une fois tous les 30 jours), votre nom (il signe vos réponses aux relecteurs), cochez la case d’âge et acceptez les conditions, puis **Créer mon espace**.

Vos modules restent sur votre ordinateur : rien n’est envoyé sans votre geste.

## Partager un module pour relecture

1. Ouvrez **Publier**. Sous **Destinations**, cochez **Relecture** (« Un lien secret pour vos relecteurs, sans compte pour eux »).
2. La première fois, vous pouvez donner un **Titre pour vos relecteurs** et **Un mot pour vos relecteurs**, qu’ils liront en ouvrant la revue.
3. Cliquez sur **Partager pour relecture**. Elabora publie cette version en privé, puis affiche **Votre revue est prête**, avec le lien : **Copier**, ou **Écrire un e-mail…** pour l’envoyer tout prêt.

Quiconque a ce lien peut lire le module et le commenter : envoyez-le seulement à vos relecteurs. Les points rouges des vérifications n’empêchent pas la relecture : on fait justement relire ce qui n’est pas fini.

Vous pouvez aussi partager depuis la vue **Revue**, avec **Partager pour relecture**.

## Envoyer une nouvelle version

Après vos corrections, retournez dans **Publier** : le bouton devient **Envoyer aux relecteurs**, et une phrase dit ce qui part (« La version 3 rejoint la revue : 2 écrans ont changé depuis la version 2. »). Le lien ne change pas. Seuls les fichiers modifiés sont envoyés, et vous pouvez continuer à travailler pendant l’envoi.

## Lire les commentaires

Vos relecteurs ouvrent le lien, cliquent sur « Commenter », puis sur ce qui les fait réagir.

- Dans la vue **Revue**, mode **Commentaires** : vos revues à gauche ; pour la revue choisie, qui la lit, quelle version ils voient, le lien, puis les fils de commentaires écran par écran, dans l’ordre du module. Filtrez par **Ouverts**, **Résolus** ou **Tous**. **Voir dans l’écran** ouvre le fil à sa place, dans Diapositive.
- Dans **Diapositive**, le bouton **Commentaires** (à côté de **Propriétés** et **Agent**) montre les fils de l’écran, avec leurs pastilles sur le canevas. Répondez sur place (⌘Entrée envoie), puis **Résoudre** ; **Rouvrir** si besoin.

Les commentaires sont relevés toutes les 30 secondes tant que le module est ouvert (et aussitôt avec **Relever maintenant**). Un point bleu sur **Revue** signale du nouveau ; sur l’accueil, la carte du module dit « 3 commentaires à traiter ». Un fil dit aussi si l’écran a changé depuis la version commentée.

Hors ligne, votre réponse reste dans son champ : rien ne part plus tard tout seul.

## Confier les corrections à votre IA

**Confier à l’agent** donne les fils ouverts au panneau **Agent**, avec une demande déjà écrite (« Corrige ces remarques. ») que vous pouvez modifier. Chaque fil part avec sa place exacte dans le module, et une règle : l’IA corrige le module, mais ne répond à personne et ne résout aucun fil. Répondre et résoudre restent vos gestes. La page de relecture prévient vos relecteurs que leurs commentaires peuvent être confiés à votre IA.

Pour que votre IA puisse aussi lire les revues d’elle-même, laissez cochée **Votre IA peut lire vos revues**, dans **Réglages** › **Compte** : elle reçoit une clé qui lit seulement.

## Gérer une revue

Le menu d’une revue propose :

- **Copier le lien**, **Renommer…**, **Modifier le mot pour les relecteurs…** ;
- **Mettre en lecture seule** (vos relecteurs lisent sans commenter ; vous pouvez encore répondre), puis **Rouvrir aux commentaires** ;
- **Fermer la revue** : le lien n’ouvre plus le module, les commentaires restent lisibles ici pendant un an, et **Rouvrir la revue** reste possible ;
- **Retirer une ancienne version…** pour libérer de la place (ses commentaires restent) ;
- **Créer un nouveau lien…** : l’ancien cesse de marcher aussitôt ;
- **Supprimer la revue…** : pour tout le monde, relecteurs compris.

Le lien est gardé sur l’ordinateur qui a créé la revue. Sur un autre ordinateur, créez-en un nouveau pour le donner. Votre compte a un nombre limité de revues ouvertes : **Réglages** › **Compte** montre où vous en êtes.
