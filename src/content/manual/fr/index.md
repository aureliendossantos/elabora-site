Elabora est une application de bureau, pour Mac et Windows, faite pour celles et ceux qui produisent des modules e-learning : indépendants, petits studios.

Vous y travaillez avec votre propre IA. C’est votre agent (Claude Code dans l’app Claude, Codex dans l’app ChatGPT, ou une autre IA à qui vous collez la demande) qui écrit le plan et les écrans. Elabora vous montre les écrans exactement comme vos apprenants les verront, et vous laisse les retoucher à la main ou annuler ce que l’agent a fait. Il garde la trace du plan que votre client a validé, recueille les commentaires de vos relecteurs par un simple lien, et livre un paquet SCORM 1.2 pour le LMS du client, ou une version web.

Elabora est en bêta : l’app évolue vite, et certaines fonctions sont marquées **Bêta**. Vos retours sont les bienvenus à contact@elabora.studio.

## Le chemin d’un module

1. Vous décrivez le module. Sur la page **Nouveau module**, vous écrivez votre demande et joignez les documents du client (brief, storyboard, maquette PowerPoint, enregistrements). Vous pouvez aussi repartir d’un module Storyline ou Rise.
2. L’agent écrit le plan. Vous le relisez, vous en faites une version (V1), vous l’envoyez au client en Word ou en PDF, puis vous notez sa validation.
3. L’agent écrit les écrans. Vous les voyez se construire, vous les retouchez à la main : textes, images, ordre des blocs, interactions, voix.
4. Vous faites relire. L’**Aperçu** joue le module comme un LMS, les **Vérifications** listent ce qui reste à corriger, et un lien de relecture permet à votre client de commenter en ligne, sans compte.
5. Vous livrez. Un paquet dans le format qu’attend le LMS du client, en une langue ou plusieurs, ou une publication sur le web.

Chaque page répond à une question pratique (« comment je fais pour… »). Les noms en gras sont ceux que vous voyez dans l’app. Quand une chose se fait en demandant à votre agent plutôt qu’avec un bouton, la page le dit et donne un exemple de demande.

L’interface d’Elabora est en français ou en anglais. Elle suit les préférences de langue de votre système, ou la langue que vous choisissez dans les **Réglages**. Le manuel existe dans les deux langues.
